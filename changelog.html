v1.2.0（2026-09-05）— 升级模式 + 数值自动复算

新增 - 升级模式 A：检查更新——顶栏显示当前版本 vX.Y.Z + "↻ 更新"按钮（服务端拉官网 version.json 对比）；/health//version 返回当前版本 - 数值任务自动复算比对：数值类交付在人工复核前自动跑一道独立复算（读交付物算式/输入再算一遍），落 auto.rechecked 事件；复核队列显示 ✅通过/⚠存疑/🔁不可用，可重跑；best-effort 不阻塞，人工复核仍是最终决策 - 品牌标注：商标注册前统一 ™（官网/App 可见品牌名） - 真自动更新（Sparkle/Squirrel）列入改造清单（成熟后再上）

v1.1.2（2026-09-05）— 上线阻塞清零版

修复 - file_ref 契约回归：自动执行/人工提交的交付证据恢复（file_missing 恒真问题），E1 上游注入恢复（下游能读到上游最新材料，不再旧版污染）；兼容旧 artifacts/ 前缀与根内绝对路径，沙箱外仍拒 403 - CI docker-e2e：前端 dist 资产纳入仓库，Docker/全新环境不再缺 assets 导致 api 起不来 - 并发复核去重：同一交付不再生成多个复核请求（幂等键绑定交付内容） - 终态守卫：任务完成/取消/归档后不能再追加交付物 - 交付物 version 字段随返工递增（同内容重试保持幂等）

其他 - vite dev 默认代理端口 8001→8020 - 升级/重启操作步骤文档化

v1.1.1（2026-09-05）— 上线前必备修复

修复 - 二次人工复核不再 409 死锁（复核请求幂等键加入轮次分量） - 任务转移去重以"最近一次转移"为准（换人重转不再误判冲突） 安全 - 新增"悬空任务"告警：归属无执行者且 30 分钟无进展 → 审计+通知一条（不再静默挂起）
