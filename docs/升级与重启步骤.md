# NG-AI-Platform 升级 / 重启操作步骤

> 适用：代码有更新后，把运行实例升到最新（本地 dev 三件套 + 发版包 + 生产服务器）。
> 核心：**改的是磁盘代码，运行进程只加载启动那一刻的 HEAD——升级=重启对应进程。**

## 0. 版本核对（先看差距）
```bash
cd ~/Desktop/ng-platform
git fetch origin -q && git status -sb          # 本地与 origin/main 差多少
git pull --rebase origin main                    # 拉最新（若有未推送本地提交，rebase 后 push）
```
运行实例加载的是启动时 HEAD：`git rev-parse HEAD` 与进程启动时间对不上 = 该重启。

## 1. 本地 dev 三件套（测试/开发）
三条分别：
```bash
# 后端 :8020（demo 模式=1 供 tester 用 demo token；测试不需要可去掉 NG_DEMO_MODE=1）
NG_DEMO_MODE=1 nohup .venv/bin/python -m uvicorn app.main:app \
    --host 127.0.0.1 --port 8020 --log-level warning >> /tmp/ng-uvicorn8020.log 2>&1 & disown
# worker
NG_DEMO_MODE=1 nohup .venv/bin/python -m app.workers >> /tmp/ng-workers.log 2>&1 & disown
# vite（前端 dev；/api 代理默认 8020，可 NG_API_TARGET 覆盖）
cd frontend && NG_API_TARGET=http://localhost:8020 nohup node_modules/.bin/vite >> /tmp/ng-vite.log 2>&1 & disown
```
探活：
```bash
curl -s http://127.0.0.1:8020/health          # 后端
curl -s http://127.0.0.1:5173/api/health      # 经 vite 打到后端（验证代理通）
```

## 2. 每次升级必须做的顺序（防漏）
1. `git pull --rebase origin main`
2. `cd ~/Desktop/ng-platform && .venv/bin/python -m pytest -q`（全绿才继续）
3. 改过前端 → `cd frontend && npm run build`（刷新 dist，桌面包/生产都吃它）
   - **记得提交 dist**：`git add -f frontend/dist && git commit …`
   - 原因（2026-09-05 CI 红）：dist 默认被 `.gitignore` 排除，不提交则 CI/Docker/全新 checkout 缺 assets，api 挂载静态目录直接崩。**每次改前端必须连 dist 一起提交。**
4. **重启 dev 三件套**（第 1 节）——否则实例还跑旧代码
5. 需要时验证新行为：注册两账号测隔离 / `PATCH …state?to=completed` 应 400 等

## 3. 发版：mac 安装包（每次出 .app/.dmg 都要重签公证）
```bash
cd ~/Desktop/ng-platform
FORCE_REPACK=1 bash scripts/sign_mac.sh      # 重打包→Developer ID 签名→公证→钉票→dist/*.dmg
```
产物 `dist/NG-AI-Platform.dmg`；验签挂载看 `source=Notarized Developer ID`。

## 4. 生产服务器（阿里云香港）
```bash
git pull origin main
DOMAIN=ng-platform.ai bash scripts/deploy.sh   # docker + caddy；compose 已 NG_ENV=production
```
- `NG_ENV=production`：未注入强 token / 默认弱 token → 拒绝启动（安全兜底，别在 dev 用）
- 数据在容器 volume + 服务器 `~/.ng-platform`；迁移 `CNAME`/DNS 见官网发布说明
- 升完 `curl https://ng-platform.ai/health`（走 Caddy）与后端探活

## 6. 常见"改了没生效"排错
| 现象 | 原因 | 处理 |
|---|---|---|
| 改了 .py 接口没变 | uvicorn/worker 没重启 | 重启三件套 |
| 前端改了没变 | dist 没重建 / vite 没重启 | `npm run build` + 重启 vite（dev 硬刷 Cmd+Shift+R）|
| demo-* token 401 | 后端没开 NG_DEMO_MODE=1 | 带环境变量重启后端/worker |
| 桌面包不是新代码 | 没重打包 | `FORCE_REPACK=1 bash scripts/sign_mac.sh` |
| 走查/P0 复验入口 | 后端 :8020 / 前端 :5173 | 注册真账号或 demo token |
