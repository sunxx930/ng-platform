# NG-AI-Platform 安装使用说明

> NG AI Platform —— 把目标交给平台，剩下它来干。
> 一个文件，安装即用，无需配置 Python / 数据库。

---

## 一、安装（Mac）

1. 下载 **NG-AI-Platform.dmg**（Mac 版安装包）
2. 双击 .dmg 打开 → 把 **NG-AI-Platform.app** 拖进「应用程序」文件夹（可选，也可直接在下载文件夹双击）
3. 首次打开若提示「无法验证开发者」：
   - 右键点 NG-AI-Platform.app → 选「**打开**」→ 再点「打开」确认（仅首次）
   - 或：系统设置 → 隐私与安全性 → 允许「NG-AI-Platform」
4. 双击应用 → **自动打开浏览器**进入界面

## 二、安装（Windows）

1. 下载 **NG-AI-Platform.exe**（Windows 版安装包）
2. 双击 .exe 运行
3. 若 Windows 弹「安全警告」/「SmartScreen」：点「**更多信息**」→「仍要运行」（仅首次，因为暂未付费数字签名）
4. 程序启动 → **自动打开浏览器**进入界面

---

## 三、开始使用

- **注册账号**：进入界面后点「去注册」，填用户名 + 密码（至少 6 位）
- **登录**：用注册的账号登录
- **提需求**：在上方输入目标（如"整理本周项目周报"）→ 点「🚀 提交」→ 平台自动拆任务、派 Agent、产出并复核
- **看板**：左侧选项目，右侧看任务看板 / 审批队列 / 审计记录

## 四、数据存在哪

- 所有数据（账号、项目、任务、审计）存在你**自己的电脑**上：
  - Mac：`~/.ng-platform/`
  - Windows：`C:\Users\你的用户名\.ng-platform\`
- 数据不传到任何服务器，**完全本地化**，删除文件夹即清除全部数据

## 五、退出 / 重新打开

- 退出：关闭浏览器页面后，在程序窗口按 **Ctrl+C**（Mac 也是 Ctrl+C）或直接关掉程序
- 重新打开：再双击一次应用即可，数据和上次一样（本地保存）

## 六、常见问题

| 问题 | 解决 |
|:--|:--|
| 打不开，提示「已损坏/无法验证」 | 见上文「安装」首次打开处理；或右键→打开 |
| 浏览器没自动打开 | 手动访问 `http://127.0.0.1:8001` |
| 端口被占用（8001 打不开） | 关掉其它占用 8001 的程序，或设环境变量 `NG_PORT=其他端口` 后重启 |
| 杀毒软件误报 | 加白名单（未付费签名前，部分杀软会误报） |
| 忘记密码 | 当前为本地账号，删 `~/.ng-platform/` 里用户文件即重置（会清数据，慎用） |

## 七、版本与更新

- 版本号见程序标题或 `健康检查`（`http://127.0.0.1:8001/health`）
- 新版本发布后，重新下载安装包覆盖即可（数据保留在 `~/.ng-platform/`）
