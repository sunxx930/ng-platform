# NG AI Platform™ 安装使用说明（v1.2.2 · 对外发布版）

> **把目标交给平台，剩下它来干。**
> NG AI Platform™ 是带责任制、可审计、不遗忘的 Agent 团队操作系统：给一个目标，
> 它自动拆解、分工、执行、复核，全程可追溯。**数据本地存储，双击即用**，无需配置 Python / 数据库。

**官网下载**：https://ng-platform.ai （Mac 版 / Windows 版）

---

## 一、安装（Mac）
> 已通过 **Apple 开发者签名 + 公证**（Developer ID，非 App Store），可正常双击打开。

1. 官网下载 **NG-AI-Platform.dmg**
2. 双击 .dmg → 把 **NG-AI-Platform.app** 拖进「应用程序」（或直接在下载文件夹双击）
3. 双击应用 → **自动打开浏览器**进入界面

## 二、安装（Windows）
1. 官网下载 **NG-AI-Platform-win.zip** → 解压得到 **NG-AI-Platform.exe**
2. 双击 .exe 运行（单文件，免安装）
3. 首次若弹 **SmartScreen**：点「**更多信息**」→「**仍要运行**」（仅首次）
4. 程序启动 → **自动打开浏览器**进入界面

---

## 三、开始使用
- **注册**：点「去注册」，填用户名 + 密码（≥6 位）
- **登录**：用注册账号登录
- **提需求**：输入目标（如"整理本周项目周报"）→ 点「🚀 提交」→ 平台自动拆任务、派 Agent、产出并复核
- **看板**：左侧选项目，右侧看任务看板 / 审批队列 / 审计记录
- **上传材料**：项目区「📤 上传材料」可传 Word / Excel / PPT / 图片 / 文本，平台自动转文本供 Agent 使用
- **交付下载**：交付完成后，审计行可 **↓DOCX/↓XLSX/↓PPTX** 下载，或 🖨 导出 PDF

## 四、数据存在哪
- 账号、项目、任务、审计、材料全部存在**你自己的电脑**：
  - Mac：`~/.ng-platform/`
  - Windows：`C:\Users\你的用户名\.ng-platform\`
- **数据不传第三方服务器**，完全本地化；删除该文件夹即清除全部数据。

## 五、退出 / 重新打开
- 退出：关掉程序窗口即可（Mac 关窗口 / Windows 关黑窗或退出程序）
- 重新打开：再双击应用，数据和上次一样

## 七、常见问题
| 问题 | 解决 |
|:--|:--|
| Mac 打不开、提示「已损坏/无法验证」 | 已签名+公证，正常不出现；若出现（多为绕过 dmg 直接拖 app），右键→打开 |
| Windows 首次被 SmartScreen 拦 | 「更多信息」→「仍要运行」（未付费数字签名的正常提示） |
| 浏览器没自动打开 | 手动访问 `http://127.0.0.1:8001` |
| 端口被占用 | 关掉占用 8001 的程序，或设环境变量 `NG_PORT=其他端口` 后重启 |
| 杀毒软件误报 | 加白名单（主要影响 Windows 版） |
| 忘记密码 | 本地账号：删 `~/.ng-platform/` 里用户文件即重置（会清数据，慎用） |

## 八、版本与更新
