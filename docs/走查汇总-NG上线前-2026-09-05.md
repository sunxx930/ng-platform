## 一句话总览

主流程（注册→拆解→自动开工→执行→交付→复核→返工→完结→审计）**全员实测闭环**，9/3 修复绝大部分真实生效；但暴露 **2 个多席位实锤的安全级 P0 + 1 个独有安全漏洞 + 1 个前端阻断项**，另有 L1 用户闭环断点需拍板口径。

## 🔴 P0-1｜复核人工门可被 PATCH 绕过（4 席独立实锤）
- 任务进入 in_review 后，任何人 `PATCH /tasks/{id}/state?to=completed` → 直接 200 完结，**全程无 review 决策**，还留孤儿 review
- 9/3 修的"强推被拦 400"只拦了 todo/in_progress→completed 非法路径；**in_review→completed 是状态机白名单合法边**，PATCH 不校验触发来源
- 叠加隔离漏洞 = 任何账号可强推他人任务完结，数值可信防线第③层（人工门）可整体跳过
- **修法**：completed 只允许 review/approval 内部事件触发；PATCH 禁直达终态（或加 L3/force-complete 标记并自动关闭未决 review）

## 🔴 P0-2｜对象级隔离缺失：只挡了列表层（7 席复现）
- "10 人互不可见"实际只过滤了 `GET /projects` 列表；**知道 project_id/task_id 即可跨账号读** tasks/audit/context，**并可写**（改状态/投毒交付物/归档他人项目）
- 9/2 串扰事故同类根因，V1.1 若多租户就是 P0
- **修法**：所有按 pid/tid 的读写端点统一 owner/成员校验（tasks/audit/context/state/deliverables/archive/review/approval 一处接入）

## 🔴 P0-3｜deliverable 可读任意服务端文件（tester 独有）
- `POST deliverables?file_ref=/etc/hosts` → 200，文件前 500 字符+hash 落审计；**可读 .env/LLM key 等任意可读文件**
- **修法**：file_ref 限定项目 artifacts 白名单目录，禁绝对路径；preview 去掉原文只留文件名

## 🟠 前端阻断项（老龙虾独有，其余多为 API 走查）
- **5173 前端 /api 代理仍指向 8001（失效端口）→ 浏览器实际无法登录使用**，页面能开但请求全 502
- 前端复核按钮：普通用户可见但点击必 403；且打回**没有 opinion 输入框**（意见传不出去，返工盲改）
- **修法**：代理改可配置指向 8020；复核按钮按 reviewer/L3 显隐；打回强制填意见；修完做一次真实浏览器回归

## 🟠 需拍板｜L1 注册用户走不完主流程（全员复现）
- 注册用户固定 L1：自动拆解任务 reviewer=平台 agent → 用户复核被 403 挡死；派单/转移需 L2 也被挡
- 影响：正式产品单用户建项目会卡 in_review 等一个不存在的 reviewer；演示也必须 L3 代审
- **三选一**：a) 项目 owner 可代审/代派自己项目；b) 支持真人账号被指派为 reviewer；c) 明确"复核归管理员/L3"，前端隐藏按钮+文档写清

## 🟡 P1/P2 其余实锤
1. 转移去重基准取最早一条而非最近 → resend 换人后再转当前 agent 误 409
2. request_review 幂等键无轮次分量 → 同任务二次人工复核 409 死锁
3. 真并发同内容提交 → 1 交付生成 4 复核请求+重复事件（check-then-act 无锁）
4. LLM 数值链式错误传播：T1 错表→T2 照抄（algo）；但意见驱动返工机制实测有效，返工质量上限=意见质量
5. 已完成任务仍可追加交付物（dev P3）、blocked 态仍可提交（quant P4）、review 决策不校验任务状态静默 no-op、exec 失败无重试无通知静默 blocked
6. owner_agent 显示名/注册名失配 → 任务静默挂起 30+ 分钟零告警
7. opinion 用 body 传被静默丢弃（query/body 契约问题）
8. HeartbeatWorker 静默冻结人工处理中任务，窗口偏紧
