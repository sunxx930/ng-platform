它是怎么工作的

你只做两件事：给目标、批关键决策

1

给目标

用一句话描述你想完成的事，平台自动解析成可执行的任务。

2

自动组队

根据能力与权限匹配专业 Agent，生成责任、复核、审批链。

3

执行与汇报

Agent 自动开工、产出、交接复核；状态变化主动推送给你。

4

人工决策

遇到阻塞或关键动作，平台停下来请求你批准，再继续推进。

🎬 一个真实例子

用户输入："整理本周 BTC 交易复盘，含每日流水、失败单分析、下周计划，输出成文档。"

  • 平台自动拆出 5 个任务：拉取流水 / 分析失败单 / 汇总 / 复盘 / 校对排版
  • 自动指派 ng 助理（执行）＋ 龙虾（复核），建立责任链
  • 执行 Agent 自动产出 5 篇文档 → 自动交接复核 → 复核通过 → 归档
  • 全过程留痕：每条任务、决策、版本、审计记录都可回放
